# Taskboard – Clean & Simple Task Manager

A fast, modern, and lightweight task manager built with vanilla HTML, modern CSS, and JavaScript (ES6+). Everything runs directly in the browser with `localStorage` persistence, zero dependencies, and a clean, clutter-free user interface.

## ✨ Features

- **Clean & Fast Task Management**:
  - **Priorities**: High, Medium, Low with visual indicator badges and color strips.
  - **Categories**: Work, Personal, Study, Health, Finance.
  - **Notes / Descriptions**: Optional expandable notes for context.
  - **Due Dates**: Smart relative badges ("Overdue", "Today", "Tomorrow") and calendar picker.
  - **Quick Date Selector**: One-click "Today" and "Tomorrow" shortcuts.

- **Smart Organization & Views**:
  - **View Tabs**: All, Today, In Progress, Urgent, and Done (with live counters).
  - **Search**: Instant real-time task search.
  - **Sorting**: Custom Order (Drag & Drop), Due Date, Priority, Recently Added, and Alphabetical.
  - **Category Filter**: Filter tasks by category with a single click.

- **Polished Aesthetics & Usability**:
  - Clean light and dark mode toggle with saved preference.
  - Inline task editing and quick delete with Undo toast notifications.
  - Drag-and-drop reordering.
  - Zero bloat, no distracting sounds or unnecessary popups.

## 🚀 How to Run

Double-click `index.html` or open it in any modern web browser. No server, node packages, or build steps required!
