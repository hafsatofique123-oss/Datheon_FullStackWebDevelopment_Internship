# Lumen & Co. – Premium E-Commerce Storefront

A realistic, modern, and high-fidelity e-commerce product catalog, shopping cart, and checkout experience built with HTML5, modern CSS3, and vanilla JavaScript.

## Features

- **Realistic High-Resolution Photography**: Professional commercial and lifestyle product photography from Unsplash for every single item across Electronics, Jewelry, Apparel, and Home Lifestyle.
- **Fail-Safe Visual Fallbacks**: Automatic graceful fallback to styled studio vector silhouettes if offline or if images fail to load.
- **Flagship Hero Showcase**: Editorial hero section featuring a featured flagship card (Aura Pro Headphones), floating micro-cards, verified customer reviews (4.9/5 from 14,200+ customers), and trust pillars.
- **Dynamic Catalog & Filtering**:
  - Filter by category with live item counts: *All (24)*, *Electronics (6)*, *Jewelry & Watches (6)*, *Apparel (7)*, *Living (5)*.
  - Price range filter (*Under $50*, *$50 – $150*, *$150+*).
  - Sorting by *Featured*, *Price: Low to High*, *Price: High to Low*, *Top Rated*, and *Biggest Savings (%)*.
  - Live search with instant multi-field matching and active filter chip reset bar.
- **Realistic Product Cards**:
  - Hover image transitions with secondary lifestyle angles.
  - Interactive color variant swatches (with real color previews).
  - Accurate pricing with crossed-out MSRPs and savings badges (*Save $50*, *-20%*).
  - Low-stock inventory indicators (*Only 3 left in stock*).
  - Wishlist heart button with persisted state.
- **Interactive Quick-View Modal**:
  - High-res multi-photo gallery with selectable thumbnails.
  - Interactive color switcher that updates selected variant name.
  - Key craftsmanship specifications with checkmarks.
  - Instant Add to Cart and Wishlist toggles.
- **Full Slide-Out Cart Drawer**:
  - Live subtotal, 8% tax calculation, and free shipping tracker ($75 goal).
  - Promo code engine with coupon codes like `WELCOME15` (15% off) and `SAVE20` ($20 off).
  - Estimated delivery date calculation.
  - Quantity steppers and instant item removals.
- **Realistic Multi-Step Checkout Modal**:
  - Shipping address and contact collection with validation.
  - Credit card form with live card brand detection (*Visa*, *Mastercard*, *Amex*), Apple Pay, and PayPal tabs.
  - Real order confirmation screen with generated Order ID (`LMN-2026-XXXXXX`), DHL tracking number, and printable receipt.
- **Persistent State**:
  - Cart and Wishlist are saved in `localStorage` so items remain across page refreshes.

## Running Locally

Open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox).
No server or build step required!
